# Device smoke на TestFlight

Проверяется на реальном устройстве после установки сборки из TestFlight.
Пока сборки не запускаются, чек-лист фиксирует, что именно нужно проверить,
чтобы не держать в голове «partial» из `PARITY.md`.

## 0. Подготовка

- [ ] Устройство с iOS 16+, TestFlight, вход в группу `Friends`.
- [ ] Два аккаунта: A и B (или A + второй телефон).
- [ ] Разрешения: уведомления, камера, микрофон, фото.
- [ ] Сеть: Wi-Fi, затем LTE, затем авиарежим.

## 1. Auth

- [ ] Вход по email-коду; код приходит, ошибки кода/кулдауна понятны.
- [ ] Вход с незарегистрированным email → «Аккаунт с таким email не зарегистрирован»,
  письмо не приходит, кнопка регистрации подставлена.
- [ ] Вход с неподтверждённым email → приходит код подтверждения, вход продолжается.
- [ ] Приложение один раз показывает подсказку о переходе на вход по коду.
- [ ] Регистрация: имя, согласие, ссылки на документы открываются.
- [ ] Закрыть/открыть приложение — сессия сохраняется (Keychain).
- [ ] Deactivate: профиль → «Удалить аккаунт» → аккаунт закрыт, чаты read-only
  у собеседника, имена скрыты; повторный вход запрещён.

## 2. Чат: текст

- [ ] Отправка, ответ, правка, удаление, копирование.
- [ ] Пересылка с комментарием; «Переслано» в пузыре.
- [ ] Реакции: свои/чужие, счётчик, «Последние».
- [ ] Закрепление: баннер, переход к сообщению, открепление.
- [ ] Мультивыбор: пересылка и удаление пачкой.
- [ ] Статусы: отправляется → отправлено → доставлено → прочитано.
- [ ] Прочтение при скролле; галочки не откатываются назад.
- [ ] Догрузка истории: скролл вверх, страница добавляется без прыжка вниз.
- [ ] Черновик сохраняется при выходе и возврате.

## 3. Чат: медиа

- [ ] Фото: мультивыбор до 10, превью, отправка, галерея, свайпы.
- [ ] Галерея: ответ, пересылка, share, сохранить в Photos.
- [ ] Видео: выбор, миниатюра в пузыре, плеер, сохранение.
- [ ] Видео-кружок: запись ≤60 c, круглая миниатюра, звук.
- [ ] Голосовое: удержание, отмена свайпом, волна, проигрывание.
- [ ] GIF: «Мои», «Этот чат», поиск Klipy, отправка, цикличный MP4.
- [ ] Файл: импорт, карточка, QuickLook, share.
- [ ] Прогресс загрузки: виден, ошибка на конкретном файле, повтор тапом.
- [ ] Авиарежим во время загрузки → ошибка → сеть вернулась → повтор.
- [ ] Перезапуск приложения с незагруженным вложением → догрузка.

## 4. Push и ссылки

- [ ] Push в чат: открывает нужный чат, подавляется, если чат открыт.
- [ ] Push новости: открывает новость.
- [ ] `muzea://chat/<uuid>`, `muzea://news/<id>` из Safari и Notes.
- [ ] `https://muzea.su/chat/<uuid>` открывает приложение (после выкладки AASA).
- [ ] Share Extension: текст и URL → выбор чата → отправка.

## 5. Лента и профиль

- [ ] Новости: фильтр, создание с изображением и видео, удаление своей.
- [ ] Жалоба на новость и видео.
- [ ] Видео: список, загрузка, проигрывание, удаление своей.
- [ ] Профиль: аватар, имя, очистка кэша (размер меняется).
- [ ] Смена языка системы на English → интерфейс на английском.
- [ ] Профиль → «Язык» → Русский/English: интерфейс меняется без перезапуска,
  выбор сохраняется после перезапуска.

## 6. Качество

- [ ] Тёмная тема: чат, композер, галерея, формы.
- [ ] Dynamic Type (крупный шрифт): пузыри и композер не ломаются.
- [ ] VoiceOver: кнопки чата, галереи, записи читаются осмысленно.
- [ ] Нет крашей при быстром скролле истории и переключении чатов.

## Что делать с найденным

1. Записать шаги, ожидание и факт, приложить скриншот/видео.
2. Завести пункт в `docs/PARITY.md` со статусом `broken`.
3. Исправить, добавить unit-тест на чистую логику, если она есть.
4. Перепроверить на следующей сборке.
